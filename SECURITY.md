# Security Policy

If you discover a security vulnerability in this project, thank you for reporting it responsibly.

- Preferred contact: create an issue labeled `security` in this repository (set the issue visibility to private), or email the maintainers at security@example.com if you require confidential disclosure.
- We will acknowledge receipt within 3 business days and communicate next steps.
- Please include steps to reproduce, affected versions, and any relevant logs or proof-of-concept code.

Please do not publicly disclose a vulnerability until it has been addressed to avoid exposing users to risk.

This repository follows a coordinated disclosure process; maintainers will work to provide a fix and public advisory when appropriate.
