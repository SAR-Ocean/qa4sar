# Contributing

Thank you for your interest in contributing to this project. Please follow these steps:

1. Fork the repository and create a feature branch from `main` or `guideliness`.
2. Run tests locally: `pytest`.
3. Follow the repository's code style (see `pyproject.toml` for ruff/mypy settings).
4. Write tests for new features or bug fixes.
5. Open a pull request describing your changes and linking any relevant issues.

For major changes, please open an issue first to discuss the design.
