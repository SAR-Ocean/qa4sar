# Developer Certificate of Origin (DCO)

This project requests that contributors sign off their commits using the DCO sign-off line.

How to sign off a commit:

```bash
git commit -s -m "A concise commit message"
```

For an existing commit, you can amend the sign-off:

```bash
git commit --amend -s
```

Pull requests should include a sign-off on each commit or a maintainer can add the sign-off during merge if the project policy allows it.

If you cannot sign off (for legal or organizational reasons), please open an issue to discuss alternative contribution pathways.
