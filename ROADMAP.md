# Roadmap

Planned work and long-term goals for the project:

- Stabilize soil-moisture workflows and reduce optional dependency footprint
- Improve test coverage for edge cases in collocation and interpolation
- Add a lightweight web-based report generator for validation summaries
- Provide prebuilt conda/pip bundles for common workflows
- Improve CI to run faster with targeted integration tests for heavy deps

This document is a living list; open issues or PRs to propose changes or reorder priorities.
