# Getting Support

If you need help using the project or running the tooling:

- For usage questions and small issues, open an issue using the "Question" or "Bug" template.
- For larger feature requests or design discussions, open an issue labeled `enhancement` and start a short design summary.
- For urgent matters, contact the maintainers listed in `MAINTAINERS.md`.

When filing an issue, include:
- OS and Python version
- Minimal reproduction steps
- Relevant logs or error messages

Community support: consider adding a mailing list or Slack/Teams channel and document it here.
